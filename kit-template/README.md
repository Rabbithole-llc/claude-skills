# My Business kit (Claude Code / Cowork)

1. Unzip this folder somewhere you'll keep it (e.g. Documents).
2. **Claude Code:** open the folder (`cd "My Business"` then `claude`). **Cowork:** give Cowork this folder.
3. Say: **"Set up my business brain."**

The skills are already inside `.claude/skills/`. Claude Code picks them up automatically. If Cowork doesn't list them, add each skill under Plugins → Add.

Using the regular Claude app instead? Download the individual skill zips from https://github.com/Rabbithole-llc/claude-skills#readme and add them under Plugins → Add → Upload plugin.
